# ניהול הודעות – Gmail, וואטסאפ ו-SMS

אפליקציית Flutter לאנדרואיד ולאייפון: סטטיסטיקות של הודעות נכנסות ויוצאות, צריכת אחסון, סיווג מיילים, וניקוי בטוח.
האפליקציה מיועדת **לשימוש אישי**. היא מותקנת ישירות על הטלפון ולא דרך החנויות.

## מה זמין בכל מכשיר

| | אנדרואיד | אייפון |
|---|---|---|
| **Gmail**: סיווג (קבלות, משפחה, פרסומות, כספים…), סטטיסטיקות, אחסון, העברה לאשפה, ארכוב, תיוג | ✅ | ✅ |
| **SMS / MMS**: נכנסות ויוצאות ביום, אנשי קשר מובילים, נפח | ✅ | ❌ אפל לא מאפשרת |
| **וואטסאפ – אחסון**: נפח תמונות, סרטונים, הודעות קוליות וכו', ומחיקת קבצים ישנים או גדולים | ✅ | ❌ (רק דרך הגדרות וואטסאפ) |
| **וואטסאפ – ספירה בזמן אמת**: הודעות נכנסות, מתוך ההתראות | ✅ | ❌ |
| **וואטסאפ – ייבוא צ'אט מיוצא**: היסטוריה מלאה, נכנסות ויוצאות | ✅ | ✅ |

**מגבלות שאי אפשר לעקוף:**
- אף אפליקציה לא יכולה לקרוא את מסד ההודעות של וואטסאפ. לכן ספירת ההודעות היוצאות מגיעה רק מצ'אטים שמייצאים ידנית.
- מחיקת SMS אפשרית רק מאפליקציית ה-SMS הראשית של הטלפון.

## פרטיות ובטיחות

- כל הנתונים נשמרים **רק בטלפון**. אין שרת, והאפליקציה פונה רק ל-Gmail עצמו.
- מהמיילים נשמרים כותרות ותקציר קצר. מ-SMS ומוואטסאפ נשמרים רק זמן, כיוון וגודל, **בלי תוכן**.
- ההרשאה ל-Gmail (`gmail.modify`) **לא מאפשרת מחיקה לצמיתות**. מיילים עוברים לאשפה ואפשר לשחזר אותם במשך 30 יום. האפליקציה לא נוגעת במיילים עם כוכב או במיילים שסומנו "חשוב".
- כל מחיקה מציגה קודם רשימה ומבקשת אישור. בניקוי מיילים מאנשים (משפחה, חברים) מופיעה אזהרה נוספת.
- מחיקת קבצי מדיה של וואטסאפ היא **סופית**, כי אין סל מחזור. ההודעות בצ'אט נשארות, אבל בלי הקובץ.

## התקנה מהירה באנדרואיד (APK מוכן)

1. העבר את `app-arm64-v8a-release.apk` לטלפון ופתח אותו. אשר "התקנה ממקורות לא ידועים".
2. בפתיחה הראשונה תן הרשאות לפי הצורך, מתוך המסכים עצמם:
   - **SMS**: לשונית SMS ← "מתן הרשאה".
   - **אחסון וואטסאפ**: לשונית וואטסאפ ← "מתן הרשאה" ← הפעלת "גישה לכל הקבצים".
   - **ספירת הודעות וואטסאפ**: לשונית וואטסאפ ← "הפעלת גישה להתראות". אם המתג אפור ("הגדרה מוגבלת"), עבור להגדרות ← אפליקציות ← ניהול הודעות ← ⋮ ← **"התרת הגדרות מוגבלות"**, ונסה שוב.
3. ל-Gmail צריך להגדיר פעם אחת גישה ב-Google Cloud. ההוראות בסעיף הבא.

## הגדרת Gmail (פעם אחת, כ-10 דקות)

1. היכנס ל-[Google Cloud Console](https://console.cloud.google.com/) וצור פרויקט.
2. **APIs & Services → Library ← Gmail API ← Enable**.
3. **Google Auth Platform → Branding**: מלא שם אפליקציה ומייל.
   ב-**Audience** בחר **External**, ותחת **Test users** הוסף את כתובת ה-Gmail שלך.
   ב-**Data Access ← Add scopes** הוסף את `https://www.googleapis.com/auth/gmail.modify`.
4. **Clients ← Create client**. צריך ליצור שני לקוחות לאנדרואיד ועוד אחד לאייפון:
   - **Web application**: שם כלשהו. העתק את ה-Client ID שלו, כי האפליקציה צריכה אותו.
   - **Android**: Package name = `com.personal.message_hub`, ו-SHA-1 של מפתח החתימה:
     - ל-APK המוכן שקיבלת: `46:B2:0B:E2:EF:80:E7:A3:AB:15:9B:DA:97:16:E2:D9:01:70:2B:D1`
     - אם אתה בונה בעצמך, הרץ `cd android && ./gradlew signingReport` והעתק את ה-SHA1 של `debug`. אפשר להוסיף כמה לקוחות Android.
   - **iOS** (רק לאייפון): Bundle ID = `com.personal.messageHub`.
5. **באנדרואיד:** באפליקציה ← הגדרות ← הדבק את ה-**Web Client ID** ← שמירה. אחר כך Gmail ← "התחברות עם Google".
6. **באייפון:** ערוך את `ios/Flutter/Google.xcconfig` לפי ההוראות שבסעיף "בנייה לאייפון".

> כל עוד האפליקציה במצב **Testing**, Google מבקש להתחבר מחדש בערך פעם בשבוע. זה תקין לשימוש אישי.
> בהתחברות תופיע האזהרה "Google hasn't verified this app". לחץ **Continue**.

## בנייה מהקוד

נדרש [Flutter](https://docs.flutter.dev/get-started/install) 3.50 ומעלה, ובנוסף Android Studio לאנדרואיד או Xcode (על Mac) לאייפון.

```bash
flutter pub get
flutter test                      # 36 בדיקות
flutter run                       # עם טלפון מחובר בכבל
flutter build apk --release --split-per-abi
```

### בנייה לאייפון

צריך Mac עם Xcode וחשבון Apple ID (חינמי מספיק).

1. ב-`ios/Flutter/Google.xcconfig` החלף את `REPLACE_ME` ב-Client ID של לקוח ה-iOS, ואת `GOOGLE_REVERSED_CLIENT_ID` באותו מזהה בסדר הפוך (מופיע בקונסול כ-"iOS URL scheme").
2. `open ios/Runner.xcworkspace` ← Runner ← Signing & Capabilities ← בחר את ה-Team שלך. אם המזהה תפוס, שנה את ה-Bundle Identifier ועדכן אותו גם בקונסול.
3. חבר את האייפון ← `flutter run --release`.
   עם Apple ID חינמי האפליקציה פגה אחרי 7 ימים וצריך להתקין מחדש. עם חשבון מפתח בתשלום ($99 לשנה) היא תקפה לשנה, ואפשר להתקין גם דרך TestFlight.

## ייבוא צ'אט מוואטסאפ (בשתי המערכות)

בוואטסאפ: פתח צ'אט ← ⋮ (באייפון: שם הצ'אט) ← **עוד ← ייצוא צ'אט** ← "ללא מדיה" או "כולל מדיה" ← שמור לקבצים.
באפליקציה: וואטסאפ ← כפתור הייבוא ← בחר את קובץ ה-`.txt` או ה-`.zip`.
- ייבוא חוזר של אותו צ'אט לא יוצר כפילויות, אז אפשר לייבא שוב מדי פעם כדי לעדכן.
- כדי שהאפליקציה תזהה הודעות יוצאות, היא צריכה לדעת את השם שלך כפי שמופיע בייצוא. אם ייבאת שני צ'אטים או יותר היא מזהה אותו לבד. אחרת, הגדר אותו במסך ההגדרות.
